🎬 Movie Ratings Analysis Dashboard

📌 Project Overview

The Movie Ratings Analysis Dashboard is a Python-based data analytics project that explores movie ratings, audience preferences, genre trends, and movie popularity using the MovieLens dataset.

The project uses interactive visualizations and a Streamlit dashboard to make movie data easy to understand.

🎯 Project Objectives

- Analyze movie rating patterns.
- Identify the highest-rated movies.
- Explore popular movie genres.
- Understand audience rating trends.
- Provide interactive movie search and analysis.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit

📊 Dataset

The project uses the MovieLens dataset:

- movies.csv
- ratings.csv

✨ Dashboard Features

1. Ratings Distribution & Trends
2. Top Rated & Popular Movies
3. Genre Insights
4. Movie Search & Individual Details
5. Precomputed Visualizations

📈 Dashboard Statistics

- Total Movies: 8,169
- Total Ratings: 89,252
- Active Users: 609
- Average Rating: 3.46 / 5.0

🚀 How to Run the Project

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder

cd Movie_Ratings_Analysis

3. Create a virtual environment

python -m venv venv

4. Activate the environment (Windows)

venv\Scripts\activate

5. Install dependencies

pip install -r requirements.txt

6. Run the dashboard

streamlit run app.py
